# 🍅 番茄钟 (Pomodoro Timer)

一个功能丰富的桌面番茄钟应用，帮助你专注工作、劳逸结合。采用 Electron + Python 多进程架构，集成菜园子游戏化激励、AI规划助手、音乐播放器等实用功能。

**最新版本：** v2.3.3 | **平台：** Windows | **许可证：** MIT

---

## 📸 功能概览

| 核心功能 | 描述 |
|---------|------|
| ⏱️ **智能计时器** | 工作/休息模式、时间预设管理、精确到秒的计时 |
| 📋 **计划模式** | 创建任务队列、拖拽排序、自动依次执行 |
| 🌱 **菜园子系统** | 种植作物、收获出售、商店买卖、成就签到 |
| 🔍 **专注模式** | 前台窗口检测、娱乐应用警告、黑白名单管理 |
| 🎵 **音乐播放器** | 播放控制、设备切换、热歌榜单、歌曲下载 |
| 🤖 **AI 规划助手** | 自然语言输入、自动生成番茄计划 |
| 📊 **数据统计** | 每日/每周/每月统计、可视化图表分析 |
| ☁️ **云端登录** | 用户认证、数据同步、Admin特权 |
| 🌙 **深色模式** | 明暗主题一键切换 |
| 📱 **迷你模式** | 桌面小组件、始终置顶、位置记忆 |


## 📚 功能详解

### ⏱️ 计时器系统

#### 三种计时模式

**单次模式** - 适合一次专注一个任务
- 点击左侧预设时间（默认：15/25/45/60分钟）
- 使用滚轮自定义时间（1-120分钟）
- 添加备注记录工作内容
- 点击「开始」启动计时

**正向模式** - 从0开始向上计数
- 不限制时长，自由专注
- 适合不确定需要多久的任务

**计划模式** - 多任务队列自动执行
- 添加多个工作/休息任务
- 拖拽调整执行顺序
- 点击「开始」自动依次执行
- 每个任务可添加详细备注

#### 工作/休息模式

点击计时器上方的按钮切换：
- **💼 工作模式**：预设 15/25/45/60 分钟，番茄红色主题
- **☕ 休息模式**：预设 5/10/15 分钟，清新绿色主题

#### 精确计时技术

采用**时间戳计算**而非简单的 `setInterval` 累加，即使应用最小化或在后台运行，也能保证计时准确性，不受浏览器节流机制影响。

### 📋 计划模式

计划模式让你可以规划一整天的专注任务，系统会自动依次执行。

**使用流程：**
1. 切换到计划模式（顶部滑块）
2. 滚轮选择时间，点击「+ 工作」或「+ 休息」添加任务
3. 可选：为任务添加备注说明
4. 拖拽任务调整顺序
5. 点击「开始」自动执行

**特性：**
- ✅ 任务拖拽排序
- ✅ 自动进入下一项
- ✅ 任务备注管理
- ✅ AI助手集成（自动生成计划）
- ✅ 状态持久化保存

### 🌱 菜园子系统

通过游戏化激励机制，让专注变得更有趣！种下种子，看着它们成长，收获后出售换取金币，购买更多种子发家致富！

#### 核心玩法

```
购买种子 → 选择种子 → 点击空格子种植 → 开启专注模式计时
    ↓
作物每分钟成长1分钟进度
    ↓
成熟后点击收获 → 获得作物和金币
    ↓
商店出售作物 → 购买更多种子
```

#### 作物图鉴

| 作物 | 图标 | 成长时间 | 稀有度 | 种子价格 | 出售价格 |
|------|:----:|:--------:|:------:|:--------:|:--------:|
| 胡萝卜 | 🥕 | 25分钟 | 普通 | 8金币 | 10金币 |
| 番茄 | 🍅 | 50分钟 | 普通 | 16金币 | 20金币 |
| 向日葵 | 🌻 | 90分钟 | 稀有 | 40金币 | 50金币 |
| 玫瑰 | 🌹 | 120分钟 | 稀有 | 64金币 | 80金币 |
| 金桂树 | 🌳 | 180分钟 | 传说 | 120金币 | 150金币 |

#### 土地解锁

初始解锁6块土地，其余土地可通过以下方式解锁：
- **金币解锁**：花费金币直接解锁
- **成就解锁**：达成特定成就免费解锁

#### 商店系统

**购买种子** - 用金币购买各种作物的种子

**出售作物** - 收获后的作物可出售：
- 单个出售：选择性地卖出
- 一键出售：全部卖出换取金币

#### 签到系统

每日签到领取奖励：
- **每日基础奖励**：胡萝卜种子 + 金币
- **连续签到**：连续天数越多，奖励越丰厚
- **每周特殊奖励**：根据星期几发放不同奖励
- **里程碑奖励**：7天、30天等特殊天数额外奖励

#### 成就系统

6大类成就等你解锁：

| 成就类型 | 说明 | 示例 |
|---------|------|------|
| 🎯 专注成就 | 累计专注时长 | 专注60分钟、120分钟... |
| 🌾 收获成就 | 累计收获作物数量 | 收获10个、50个... |
| 🌱 种植成就 | 累计种植次数 | 种植20次、100次... |
| 🎒 收集成就 | 收集不同作物种类 | 收集3种、5种... |
| 💰 财富成就 | 累计获得金币 | 获得100金币、500金币... |
| 💪 坚持成就 | 连续签到天数 | 连续7天、30天... |

#### 惩罚机制

专注模式下，以下行为会导致**所有正在生长的作物枯萎死亡**：
- ❌ 手动点击「重置」中断计时
- ❌ 前台检测累积3次警告
- ❌ 专注模式下关闭窗口

**保护机制：**
- 专注模式下禁用「暂停」按钮
- 专注模式下禁止种植新作物
- 关闭窗口前弹出确认对话框

### 🔍 专注模式

专注模式与前台检测联动，防止你在专注时分心刷娱乐应用。

#### 开启方式

点击计时器下方的「专注模式」开关即可开启。开启后：
- 计时运行时自动启动前台检测
- 参与菜园子奖惩机制（作物会成长/枯萎）
- 禁用暂停按钮，防止作弊

#### 前台检测逻辑

```
检测到前台窗口变化
    ↓
匹配白名单？ ──是──→ ✅ 通过（不警告）
    ↓否
匹配黑名单？ ──是──→ ⚠️ 警告
    ↓否
查询历史记录？ ──有记录──→ 根据历史判断
    ↓无记录
调用 DeepSeek AI 判断 ──是娱乐──→ ⚠️ 警告
    ↓不是娱乐
✅ 通过（记录到历史）
```

#### 警告系统

检测到娱乐前台时弹出警告弹窗：

```
┌─────────────────────────────────┐
│           ⚠️                    │
│     检测到娱乐前台               │
│   【B站 - 某视频标题】           │
│     警告次数：1/3                │
│                                 │
│ [不是娱乐]      [知道了]         │
└─────────────────────────────────┘
```

**按钮说明：**
- **不是娱乐**：将当前窗口标记为非娱乐，加入白名单或历史记录
- **知道了**：承认警告，累积警告次数

#### 惩罚触发

累积 **3次** 警告后触发惩罚：
1. 🥀 所有正在生长的作物枯萎
2. 🔄 计时器自动重置
3. 🔴 专注模式自动关闭
4. 🔔 播放悲伤音效并显示损失详情

#### 黑白名单管理

配置文件：`foreground_inspection/list_config.json`

**默认白名单**（不会被警告）：
- 文件资源管理器
- Visual Studio Code
- PowerShell
- PowerPoint
- 番茄钟自身

**默认黑名单**（直接警告）：
- bilibili
- 抖音
- 快手
- 斗鱼
- 虎牙

#### AI判断（Admin特权）

非黑白名单的窗口，Admin用户可使用DeepSeek AI进行智能判断：
- AI分析窗口标题，判断是否为娱乐应用
- 判断结果保存到历史记录，下次直接使用
- 大幅提高检测准确率，减少误判

**获取Admin权限：**
1. 注册账号并登录
2. 联系管理员将你的账户设置为admin角色
3. 重新登录即可自动获取API Key

#### 基本操作

| 操作 | 方式 |

| **调节音量** | 点击 🔊 展开音量滑块 |

- 支持多个音频设备（扬声器、耳机等）

将音乐文件放入 `music-player/music/` 文件夹：

### 🤖 AI 规划助手

使用自然语言描述你的需求，AI自动生成合理的番茄钟计划。

#### 使用条件

- 需要 **Admin用户** 登录
- Admin用户自动获取DeepSeek API Key（仅内存存储）

#### 使用方法

1. 点击顶部「🤖」按钮打开AI助手
2. 在输入框中描述你的需求，例如：
   - "我要学习3小时"
   - "准备考试，每学习45分钟休息10分钟"
   - "写代码2小时，中间休息两次"
   - "明天要复习数学、英语、物理各1小时"
3. 点击「✨ 生成计划」
4. 查看AI生成的计划详情
5. 点击「✅ 应用计划」自动添加到计划模式

#### 生成示例

**输入：**
```
明天要考试，需要复习数学3小时
```

**AI输出：**
```
📋 为您规划了3小时的数学复习计划

1. 💼 工作 45分钟 - 复习数学第一部分
2. ☕ 休息 10分钟
3. 💼 工作 45分钟 - 复习数学第二部分
4. ☕ 休息 10分钟
5. 💼 工作 45分钟 - 复习数学第三部分
6. ☕ 休息 15分钟

⏱️ 总计: 3小时5分钟
```

#### Prompt设计原理

AI助手经过精心设计的Prompt引导，确保生成的计划：
- 合理分配工作和休息时间
- 遵循番茄钟经典比例（45+10或25+5）
- 考虑长时间专注的疲劳因素
- 输出结构化JSON格式，便于程序处理

### 📊 数据统计

记录并可视化你的专注数据，帮助你了解自己的工作习惯。

#### 查看统计

点击顶部「📈」按钮打开统计弹窗。

#### 时间范围

| 范围 | 说明 | 图表展示 |
|------|------|---------|
| **每日** | 最近7天的数据 | 每天一个柱状图 |
| **每周** | 最近4周的数据 | 每周一个柱状图 |
| **每月** | 最近6个月的数据 | 每月一个柱状图 |

#### 图表类型

点击图表类型按钮切换：

| 类型 | 图标 | 适用场景 |
|------|:----:|---------|
| **柱状图** | 📊 | 对比每天的专注时长 |
| **折线图** | 📈 | 观察长期趋势变化 |
| **饼状图** | 🥧 | 查看各备注类别占比 |

#### 统计指标

- **专注次数**：完成的番茄钟数量
- **专注时长**：累计专注分钟数
- **平均时长**：每次专注的平均时长
- **详细数据表格**：每日/周/月的具体数据

#### 备注分类统计

如果你在计时时添加了备注，统计会按备注类别分组显示：
- 柱状图按备注堆叠显示不同颜色的区块
- 饼图显示各类备注的时长占比
- 帮助你了解时间都花在了哪些事情上

#### 数据持久化

统计数据自动保存到本地数据文件：
- 路径：`%APPDATA%/pomodoro-timer/data/data.json`
- 每次计时完成自动记录
- 部分完成的专注时间也会记录（带备注）

### ☁️ 云端登录

支持用户注册登录，Admin用户可使用高级功能。也支持本地配置API Key模式。

#### 登录/注册

点击顶部「☁️」按钮打开登录窗口：

**注册新账号：**
1. 切换到「注册」标签
2. 输入用户名（至少2字符）
3. 输入密码（至少6位）
4. 点击「注册」

**登录已有账号：**
1. 输入用户名和密码
2. 可选：勾选「记住密码」和「自动登录」
3. 点击「登录」

#### 两种模式

登录窗口顶部有模式切换拨杆：

**☁️ 云端登录模式**（默认）
- 使用Supabase进行用户认证
- Admin用户自动获取API Key
- API Key仅存内存，退出登录即清除
- 适合大多数用户

**⚙️ 本地配置模式**
- 不依赖云端服务
- 手动输入DeepSeek API Key
- API Key持久化保存到本地
- 适合有自己的API Key的用户

**注意：** 切换模式会清除另一模式的数据（云端模式清除本地API Key，本地模式清除云端登录凭据）。

#### Admin特权

Admin用户享有以下特权：
- ✅ 自动获取DeepSeek API Key
- ✅ 使用AI规划助手生成计划
- ✅ 前台检测使用AI判断（准确率更高）
- ✅ 热歌榜单歌曲下载功能

**如何获取Admin权限：**
1. 注册账号并登录
2. 联系项目管理员
3. 在Supabase Dashboard中将你的用户记录的 `admin` 字段设置为 `true`
4. 重新登录即可

#### 安全说明

**云端模式：**
- 密码使用PBKDF2 + SHA512哈希存储
- API Key仅在内存中，不写入磁盘
- 退出登录后自动清除所有敏感信息

**本地模式：**
- API Key加密存储到本地数据文件
- 妥善保管，不要分享给他人

- 文字：浅灰色 #eee
- 强调色：亮番茄红 #ff8787

#### 状态持久化

主题选择自动保存，下次启动应用时恢复。

### 📱 迷你模式

计时运行时最小化窗口进入迷你模式，变成桌面小组件。

#### 进入迷你模式

计时运行时点击「−」最小化按钮：
- 窗口缩小为 180x220 的小组件
- 始终置顶显示在其他窗口上方
- 显示圆形进度条和时间
- 可拖动到桌面任意位置

#### 退出迷你模式

有三种方式：
1. 点击迷你窗口底部的「⬆」按钮
2. 右键系统托盘图标，选择「展开窗口」
3. 关闭迷你窗口（需确认）

#### 系统托盘

迷你模式下会在系统托盘显示番茄图标：
- **左键点击**：显示/聚焦窗口
- **右键菜单**：
  - 展开窗口
  - 退出应用

#### 位置记忆

迷你模式的位置会被记住：
- 拖动到新位置后自动保存
- 下次进入迷你模式时恢复到相同位置
- 方便固定在桌面角落

### 📝 备注功能

为每个番茄钟添加备注，方便记录工作内容，后续可在统计中查看。

#### 单次模式备注

1. 选择时间后，在计时器圆圈上方出现备注输入框
2. 输入标题（最多10字符）
3. 点击 ✓ 确认
4. 确认后显示备注文字和编辑按钮 ✏️
5. 点击 ✏️ 可重新编辑

#### 计划模式备注

1. 在滚轮选择器下方展开备注区域
2. 输入标题（可选，最多50字符）
3. 输入详细内容（可选）
4. 点击「+ 工作」或「+ 休息」添加带备注的任务
5. 任务列表中显示 📒 图标表示有备注
6. 点击 📒 可查看/编辑/删除备注

#### 统计中显示

备注会在数据统计中发挥作用：
- 柱状图按备注类别堆叠显示不同颜色
- 饼图显示各备注类别的时长占比
- 详细数据表格中显示每条备注
- 帮助你分析时间分配情况

## 🛠️ 技术架构

### 多进程架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Electron 主进程                           │
│  - 窗口管理（主窗口、菜园子窗口）                              │
│  - IPC 通信路由                                              │
│  - 系统托盘                                                  │
└───────────────┬─────────────────────────────────────┬───────┘
                │ stdin/stdout (JSON Lines)           │ stdin/stdout (JSON Lines)
                ▼                                     ▼
┌───────────────────────────┐         ┌───────────────────────────┐
│   music.exe (Python)      │         │ foreground_inspection.exe │
│   - 音频播放控制           │         │ - 前台窗口检测            │
│   - 设备管理               │         │ - AI 娱乐判断             │
│   - 快捷键监听             │         │ - 黑白名单管理            │
└───────────────────────────┘         └───────────────────────────┘
```

### 核心技术栈

- **前端框架：** Electron 34.0.0
- **UI技术：** HTML5/CSS3/JavaScript (ES6)
- **数据可视化：** Chart.js 4.5.1
- **后端子进程：** Python 3.x
- **音频处理：** sounddevice, soundfile
- **AI服务：** DeepSeek API
- **云端服务：** Supabase（用户认证、数据库）

### 数据存储

**本地数据：**
- 路径：`%APPDATA%/pomodoro-timer/data/data.json`
- 内容：统计数据、预设、菜园子数据、设置等

**云端数据：**
- Supabase Authentication：用户认证
- Supabase Database：Admin用户的API Key管理
