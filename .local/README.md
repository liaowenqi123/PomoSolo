# `.local/` —— 本地私密区（契约说明）

> **本文件是 `.local/` 里唯一入库的文件。** 同目录其余内容全部被 `.gitignore` 忽略，只存在于本机。
> 部门：主部门 ｜ 建立：2026-09 仓库重构

---

## 1. 这个目录解决什么问题

项目有**越来越多的信息必须在文件夹里存在，但绝不能上 GitHub**：
本机工具链路径、服务器 SSH 细节、测试账号、密钥位置、运维备忘、发版踩坑记录。

历史做法是"统一塞进 `temp-debug/`"，但那个目录的语义是**一次性调试产物**，
和**长期有效的本机配置**混在一起。因此拆成两个目录，职责单一：

| 目录 | 语义 | 生命周期 | 入库 |
|------|------|---------|------|
| `.local/` | **本机/服务器专属事实与密钥引用**（长期有效） | 跟着这台机器走 | ❌ 仅本 README |
| `temp-debug/` | **一次性调试脚本 / 临时产物**（用完即弃） | 一次性 | ❌ 全部 |

**判断口诀**：这条信息*换一台机器就不一样*或*泄漏会造成损失* → `.local/`；
*只是这一次排查用* → `temp-debug/`。

## 2. 放什么 / 不放什么

### ✅ 应该放 `.local/`

- 本机路径与工具链位置（Node/Rust/Chrome/adb/actions-runner 在哪）；
- **密钥、token、密码的"位置引用"**（写成 `见 C:\Users\...\.tauri\pomosolo.key`，而不是把私钥内容贴进来）；
- 服务器访问方式（SSH 别名、部署目录、重启命令、数据库连法）；
- 测试账号、测试房间号、设备编号；
- 本机网络坑（DNS 劫持、代理、端口占用）；
- 发版时只有这台机器才有的前置条件。

### ❌ 不要放 `.local/`

- **源码、文档、配置模板** —— 这些必须在克隆里就存在，放 `src/`、`docs/`、仓库根；
- **任何新 agent 必须知道才能工作的事** —— 那是 `AGENTS.md` + `docs/` 的职责。
  `.local/` 只装"锦上添花"的本机事实，**缺了它项目照样能跑通、能发版**（只是要重新查一遍环境）。

> 这条边界很重要：`.local/` 是**加速层**，不是**真相层**。真相永远在入库文件里。

## 3. 约定（新 agent 请照此读写）

### 文件命名

| 文件 | 内容 |
|------|------|
| `MACHINE.md` | 本机工具链路径、可用浏览器、adb、CI runner、缓存目录 |
| `SERVER.md` | 服务器 SSH / 部署目录 / 重启命令 / 数据库 / 更新源 |
| `SECRETS.md` | 敏感物**清单 + 位置**（不写值） |
| `ACCOUNTS.md` | 测试账号、测试数据 |
| `ANDROID.md` | 安卓端仓库本地路径与开发/截图命令 |
| `RELEASE.md` | 发版前置条件与本机网络坑 |
| `*.local.md` | 任意补充，`*.local.md` 后缀便于识别 |

新增文件请**先在本表登记**，保持可发现。

### 对 agent 的要求

1. **启动时读 `AGENTS.md`（入库，权威）；`.local/` 只在需要本机/服务器细节时读**，
   并且**只读不写**——除非用户明确要求记录本机事实；
2. 从 `.local/` 读到的东西**不要复制进入库文档**（那正是把它放这儿的原因）；
3. 发现某条信息"换机器也成立"，**不要写进 `.local/`**，写进 `docs/` 或 `AGENTS.md`。

## 4. 安全底线

- 本目录整体被 `.gitignore` 忽略。**提交前确认 `git status` 里不出现 `.local/` 下的文件**：
  ```bash
  git status --short | grep -i '\.local/'   # 应无输出（README.md 除外）
  git check-ignore -v .local/MACHINE.md     # 应打印 .gitignore 命中行
  ```
- **私钥本体一律留在仓库外**（如 `C:\Users\admin\.tauri\pomosolo.key`），
  `.local/SECRETS.md` 只记录**它在哪、怎么用**，不记录**它是什么**；
- 若误把私密内容写进入库文件并已 push，**必须轮换该凭据**，仅删除文件不算修复。
