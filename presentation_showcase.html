1. Background, Motivation, Problem Statement

Background: Students often use simple timers, but those tools do not actively prevent distraction or sustain motivation over long study periods.

Motivation

  • Turn focus sessions into a habit, not a one-time action.
  • Combine timer + behavior supervision + positive feedback.

Problem & Goal

  • Pain point: easy to switch to entertainment apps.
  • Goal: build a practical desktop system that improves focus continuity and study visibility.

2. System Overview

Architecture (Multi-process)

Electron main process manages UI, window lifecycle, IPC routing and system tray.

Python subprocesses handle music control and foreground inspection through JSON-lines stdin/stdout communication.

Tech Stack

  • Electron 34 + JavaScript (ES6)
  • Python subprocess services
  • Chart.js for visualization
  • Supabase for authentication and cloud data

5. Engineering Highlights

Process Reliability

  • Subprocess orphan-process issue fixed by stdin disconnect detection.
  • Crash-safe exit design for child processes.

Data & Concurrency

  • Separated settings/data files to reduce concurrent write conflicts.
  • Garden module supports atomic operations and synchronization.

Collaboration Practice

  • Git commit conventions (feat/fix/docs/refactor/chore).
  • Bug-fix records and architecture docs maintained in docs/.

Build & Delivery

  • Automated packaging scripts (npm run build, installer build).
  • Windows executable and installer distribution ready.

6. Current Limitations & Next Steps

Current Limitations

  • Desktop-first implementation, mainly optimized for Windows distribution.
  • Some advanced AI features require Admin permission and API key setup.
  • Music-source integration and network-dependent features need stable connectivity.

Next Steps

  • Cross-platform packaging and compatibility testing.
  • Expand test coverage for end-to-end user flows.
  • Refine AI classification transparency and user controls.
  • Improve study-room robustness under larger concurrent usage.
