📖 使用说明

⏱️ 单次模式

• 点击左侧预设设置时间，或用滚轮自定义（1-120分钟）

• 点击 "+" 添加新预设，点击 "×" 删除预设

• 选定时间后可以在右侧倒计时上方增加备注

📝 计划模式

• 滚轮选时间，点击 "+ 工作"/"+ 休息" 添加任务

• 拖拽调整顺序，点击"开始"依次执行

🎯 迷你模式

• 计时运行时点击最小化进入迷你模式

• 窗口缩小为桌面小组件，始终置顶

• 可拖动到任意位置，位置会被记住

🌙 深色模式

• 点击顶部按钮切换深色/浅色主题

🌱 专注模式

• 开启专注模式后参与奖惩机制

• 计时运行时作物会成长

• 点击 🌱 按钮打开菜园子管理作物

🔍 前台检测

• 专注模式下会检测当前前台窗口

• 切换到娱乐应用会收到警告

• 3次警告作物枯萎

• 可标记"不是娱乐"避免误判

• Admin 用户登录后使用，判断更准确

🌻 菜园子

• 种下种子，收获作物

• 作物出售，换取金币

• 金币购买种子，种子种植作物，发家致富！

🎵 音乐播放器

• 播放控制：播放/暂停、上下首

• 点击歌名展开播放器详情

• 拖动进度条跳转播放位置

• 点击设备按钮切换输出设备

• 点击音量图标调节音量

⌨️ 快捷键

• 右Ctrl + 右Shift：暂停/播放

• 右Ctrl + ←：上一曲

• 右Ctrl + →：⬇下一曲

• 右Ctrl + ↑：增大音量

• Ctrl + ↓：减小音量

📊 数据统计

• 点击 📊 按钮查看专注统计

• 显示专注次数、总时长、平均时长

📅 时间范围

• 每日：查看当天数据

• 每周：查看本周数据

• 每月：查看本月数据

📈 详细记录

• 查看每次专注的备注和时长

• 图表直观展示专注趋势

🤖 AI规划助手

• 需要 Admin 用户登录后使用

• 点击 🤖 按钮打开AI助手

• 用自然语言描述您的需求

• 示例："我要学习3小时，每45分钟休息10分钟"

✨ 生成计划

• AI会根据您的描述生成计划

• 点击"应用计划"自动添加到计划模式

• 可在应用前手动调整

☁️ 云端登录

• 注册账号或登录已有账号

• 数据可云端同步

🔐 Admin 账户

• Admin 用户自动获取 DeepSeek API Key

• 可使用 AI 规划助手功能，增强前台检测功能

• API Key 仅在内存中，安全可靠

👤 普通用户

• 可使用基础番茄钟功能

• 可使用音乐播放器

• 可使用统计功能

🤖 AI规划助手

💡 提示：描述您的任务内容、时长需求，AI会为您规划合理的番茄钟计划
