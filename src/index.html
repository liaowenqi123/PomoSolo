📖 使用说明

⏱️ 计时模式

• 单次模式：点击左侧预设时间，或滚轮自定义（1-120分钟）

• 正向模式：从0开始向上计时，不限时长

• 计划模式：添加多个任务，自动依次执行

• 点击上方按钮切换 💼 工作 / ☕ 休息 模式

⏰ 预设管理

• 点击 "+" 添加新预设时间

• 点击 "×" 删除不需要的预设

• 滚轮可临时调整当次时间

📝 备注功能

• 选择时间后可添加备注记录工作内容

• 备注会显示在统计中，帮助分析时间分配

📱 迷你模式

• 计时运行时最小化进入迷你模式

• 桌面小组件，始终置顶，可拖动

• 可在设置中选择退出方式

🎯 专注模式

• 开启后参与菜园子奖惩机制

• 计时运行时作物成长，作弊则枯萎

• 禁用暂停按钮，防止偷懒

🔍 前台检测

• 检测当前前台窗口是否为娱乐应用

• 切换到娱乐应用会收到警告

• 累积 3次警告 作物枯萎

• 可标记"不是娱乐"避免误判

• Admin 用户可使用 AI 判断，更准确

📋 黑白名单

• 白名单：不会被警告（VS Code、PPT等）

• 黑名单：直接警告（B站、抖音等）

• 其他窗口由 AI 智能判断

🎵 音乐播放器

• 播放控制：播放/暂停、上下首切换

• 点击歌名展开播放器详情

• 拖动进度条跳转播放位置

• 点击 🎧 切换音频输出设备

• 点击 🔊 调节音量

• 点击 ☰ 查看播放列表

• 点击 📊 查看热歌榜单

⌨️ 全局快捷键

• 无需聚焦窗口即可控制播放

• 默认快捷键（可在设置中自定义）：

　 右Ctrl + 右Shift：暂停/播放

　 右Ctrl + ←/→：上一首/下一首

　 右Ctrl + ↑/↓：音量增/减

• 支持区分左右 Ctrl/Alt/Shift

🌱 核心玩法

• 种植：选择种子 → 点击空格子

• 成长：专注模式下每分钟成长1分钟

• 收获：成熟后点击收获获得作物

• 出售：商店出售作物换取金币

• 购买：金币购买更多种子

🌾 作物图鉴

• 🥕 胡萝卜：25分钟，普通

• 🍅 番茄：50分钟，普通

• 🌻 向日葵：90分钟，稀有

• 🌹 玫瑰：120分钟，稀有

• 🌳 金桂树：180分钟，传说

⚠️ 惩罚机制

• 重置计时、累积警告、关闭窗口

• 以上行为会导致作物 枯萎死亡

📊 数据统计

• 点击 📈 按钮查看专注统计

• 显示专注次数、总时长、平均时长

📅 时间范围

• 每日：最近7天的数据

• 每周：最近4周的数据

• 每月：最近6个月的数据

📈 图表类型

• 📊 柱状图：对比每天的专注时长

• 📈 折线图：观察长期趋势变化

• 🥧 饼图：查看各备注类别占比

📝 备注分类

• 备注会按类别分组统计

• 帮助你了解时间分配情况

🤖 AI规划助手

• 需要 Admin 用户 登录后使用

• 点击 🤖 按钮打开AI助手

• 用自然语言描述您的需求

💡 使用示例

• "我要学习3小时"

• "每学习45分钟休息10分钟"

• "复习数学、英语、物理各1小时"

✨ 生成计划

• AI 会根据描述生成合理计划

• 遵循番茄钟经典比例（45+10）

• 点击"应用计划"自动添加到计划模式
