## 0. 设计理念

### 0.1 一句话定位

> **菜园是专注的影子，不是主菜。**

用户打开 App 的核心目的是"专注"，菜园只是把"专注了多久"翻译成看得见的反馈。一切设计必须服从这条铁律。

### 0.2 四条铁律

1. **轻**：所有种菜操作 ≤5 秒完成、≤2 步，绝不打断专注流程
2. **平**：成长体系极端扁平，专注 1 小时和 8 小时的用户菜园差异 ≤3 倍，杜绝"种菜焦虑"
3. **暖**：离线/断签只温和召回，绝不惩罚（无作物死亡、无进度清空——专注违规惩罚是另一套独立机制）
4. **峰**：情绪峰值靠低频彩蛋（偷菜小动物、变异闪光、流星雨），不靠数值膨胀

## 1. 六维度设计详解

### 维度 1：用户接受门槛（极度轻量）

#### 1.1 问题

当前菜园是独立窗口（400×520），需要用户主动打开；种植需要"点空地 → 轮盘选种"两步。对"只想专注"的用户，任何一个多余步骤都是流失点。

#### 1.2 交互设计

| 场景 | 当前 | 重构后 | 操作耗时 |
|------|------|--------|----------|
| 查看菜园状态 | 打开独立窗口 | 主界面右下角 32px 角标 + 状态点（收获就绪亮黄点） | 0s（无需操作） |
| 进入菜园 | 打开窗口 | 点角标 → 窗口秒开（预加载） | ≤1s |
| 种植 | 点空地 → 轮盘选种 | **快捷种植**：点空地默认种"当前最优种子"（按库存/性价比），长按才出轮盘 | ≤3s |
| 收获 | 逐块点击成熟作物 | **一键全收**：成熟作物全部入库 + 角标熄灭 | ≤2s |
| 出售 | 进商店逐项卖 | 一键出售（已有 sell_all）+ 商店批量 | ≤2s |
| 反馈 | — | 所有种菜反馈用**角标/轻提示**，不用模态弹窗 | — |

**交互细则**：
- 主界面角标：`🍅` 图标 + 右上角状态点（绿色=生长中，黄色=有成熟待收，红色=有枯萎待救）
- 菜园窗口顶部常驻一行"状态条"：`🌱 3块地生长中 · 2 株待收 · 🔥连击×2`
- 快捷种植的"最优种子"算法：优先选 `库存中性价比最高且能在预计剩余专注时间内成熟` 的种子
- 所有按钮触控目标 ≥ 44px；菜园窗口保持 400×520 固定尺寸
- 专注过程中菜园**完全后台静默生长**，不弹任何窗口

#### 1.3 数值

- 单次操作耗时目标：种植 ≤3s、收获 ≤2s、其他 ≤5s
- 主界面菜园入口视觉面积：1 个 32px 图标（不占导航空间）
- 状态点颜色映射：绿/黄/红三态

### 维度 2：难度/激励梯度（段位可视化）

#### 2.1 问题

现有"成就系统"是横向清单（25 个），没有纵向的"段位成长"感知。用户不知道自己"坚持专注"会带来什么形态变化。

#### 2.2 段位系统设计

**段位 = 连续专注天数**（复用现有 `signIn.continuousDays`，语义一致）

| 段位 | 名称 | 连续天数 | 菜园形态变化 |
|------|------|----------|--------------|
| Lv0 | 萌芽 | 0-6 | 光秃秃的土地 |
| Lv1 | 初绿 | 7 | 出现栅栏、小草、微风动画 |
| Lv2 | 繁茂 | 14 | 蝴蝶飞舞、花朵装饰、土地变沃土色 |
| Lv3 | 丰收 | 30 | 金色麦浪、彩虹、星星粒子 |

**交互示意**：
- 菜园背景随段位渐变（CSS 渐变 + 装饰元素），升段时有 1 秒粒子庆祝动画
- 主界面角标显示段位小徽章（`Lv1` 字样）
- 段位解锁额外**装扮碎片**（见维度 3 数值出口）

#### 2.3 断签处理（轻惋惜、不劝退）

| 断签时长 | 视觉 | 影响 | 恢复方式 |
|----------|------|------|----------|
| 0-3 天（宽限期） | 叶子微微发黄 | 段位保留 | 完成 1 个番茄钟自动恢复翠绿 |
| 超过 3 天 | 叶子明显发黄 + 角落提示 | **段位降 1 级**（Lv2→Lv1，绝不直接清零） | 完成 1 个番茄钟恢复生机，段位按当前连续天数重新计算 |

**关键设计**：
- 断签 ≠ 惩罚：不扣金币、不消失作物、不重置成就
- 降级是"软着陆"：每次只降 1 级，最低到 Lv0，永远保留"历史最高段位"记录供展示
- 断签提示文案温暖化："🌱 你的菜园有点蔫了，完成一个番茄钟就能恢复生机"

#### 2.4 数值

- 段位阈值：7 / 14 / 30 天（与现有签到里程碑 7/14/30 对齐）
- 宽限期：3 天（断签 1-2 天内心态无压力）
- 降级：超过宽限期降 1 级/次，最低 Lv0
- 历史最高段位：永久记录（`tierBest`），用于成就/分享

### 维度 3：数值克制（扁平成长 + 封顶）

#### 3.1 问题

作物性价比曲线单调递增（0.40→0.83/min，约 2 倍差距），且没有收益封顶。重度用户可能为了收益过度专注（违背产品初衷），或产生"我 8 小时才有的大园子，他 1 小时也有"的焦虑。

#### 3.2 扁平化原则

> 菜园收益来自"**完成番茄钟这个行为**"本身，而不是"专注了多少分钟"。1 个番茄钟和 8 个番茄钟的差异，体现在收获次数上，但被**每日上限**封顶。

#### 3.3 每日封顶逻辑

| 封顶项 | 数值 | 说明 |
|--------|------|------|
| 每日有效生长分钟 | **120 分钟** | 超过后生长停止，提示"🌿 今日菜园已满，明天再来" |
| 每日金币收益 | **100 金币** | 超过后收获的作物仅入库，金币不再增加 |
| 每日收获次数 | **无硬上限** | 但受生长封顶制约（120 分钟最多收 4-5 株胡萝卜） |
| 连击加成 | ×1.5（已有） | 不再叠加 |

#### 3.4 专注 1 小时 vs 8 小时对比

| 指标 | 专注 1 小时（约 2 个番茄钟） | 专注 8 小时（约 16 个番茄钟） | 差异 |
|------|------------------------------|------------------------------|------|
| 有效生长 | 120 分钟（已达上限） | 120 分钟（封顶） | **1:1** |
| 收获次数 | 约 4-5 株胡萝卜 | 约 4-5 株胡萝卜 | **1:1** |
| 金币 | 40-50 | 100（封顶） | **1:2** |
| 段位 | 看连续天数 | 看连续天数 | 公平 |

**结论**：8 小时用户顶多是 2 倍差距，且这 2 倍来自"坚持天数"而非"单日时长"，符合"奖励坚持而非透支"的原则。

#### 3.5 金币的长期出口（防通胀）

| 出口 | 成本 | 说明 |
|------|------|------|
| 解锁土地 | 共 1650 金币（已有） | 2-4 周解锁完 |
| 段位装扮 | 每级 200-500 金币 | 新的情绪出口（栅栏/蝴蝶/稻草人/风车） |
| 图鉴收集 | — | 通过收获/变异驱动，非金币 |
| 每日封顶 | 100 金币/天 | 防止极端囤积 |

**数值平衡检查**：
- 日均收入（正常用户）：30-50 金币 → 土地全解锁约 4-6 周
- 装扮是"消耗型欲望"：买完不会后悔，还会想要下一件

#### 3.6 交互示意

- 达到生长上限：菜园顶部状态条变为"🌿 今日菜园已满，明天再来"（不弹窗）
- 达到金币上限：收获时轻提示"已超过今日金币上限，作物已入库"
- 段位装扮：菜园窗口底部新增"装饰"页签，金币购买后即时生效

### 维度 4：惊喜与随机性（低频彩蛋）

#### 4.1 设计原则

彩蛋**只增不减**（只给奖励不扣东西）、**低频**（防止麻木）、**低成本实现**（纯前端 + 少量后端状态）。

#### 4.2 三个彩蛋

##### 彩蛋 A：偷菜小动物 🐿️

- **触发**：专注结束后 5% 概率
- **表现**：菜园角落出现一只随机小动物（松鼠/兔子/刺猬，跑动动画）
- **交互**：点击小动物 → 抖动 + 掉落奖励（随机种子 1-2 颗 或 5-10 金币）
- **冷却**：24 小时（防止刷）

##### 彩蛋 B：变异闪光作物 ✨

- **触发**：收获时 3% 概率
- **表现**：收获动画变闪光特效，作物图标带 ✨ 标记
- **奖励**：该株作物价值 ×3
- **附加**：点亮图鉴"闪光版"条目（收集钩子，收集全部 5 种闪光作物有专属成就）

##### 彩蛋 C：流星雨 🌠

- **触发**：连续专注 3 天后，次日首次打开菜园 10% 概率
- **表现**：菜园背景 5 秒流星动画
- **奖励**：掉落 1 颗稀有种子（向日葵/玫瑰）
- **冷却**：无（本身低概率）

#### 4.3 数值汇总

| 彩蛋 | 概率 | 冷却 | 奖励 |
|------|------|------|------|
| 偷菜小动物 | 5%/次专注结束 | 24h | 种子 1-2 颗 或 5-10 金币 |
| 变异闪光 | 3%/次收获 | 无 | 价值 ×3 + 图鉴条目 |
| 流星雨 | 连续 3 天 + 10% | 无 | 稀有种子 1 颗 |

**情绪峰值验证**：三天彩蛋分布在"专注结束/收获/次日打开"三个不同时刻，制造低频但稳定的期待感。

### 维度 5：离线/断签处理（温和召唤）

#### 5.1 设计原则

> 用户不是欠菜园的，菜园是等用户的。任何离线状态都**不惩罚、可逆转、带召唤感**。

#### 5.2 三级状态机

| 状态 | 触发条件 | 视觉 | 恢复方式 |
|------|----------|------|----------|
| 正常 | 活跃使用 | 翠绿 | — |
| **微黄** | 断签/离线 >24h | 叶子颜色变淡、角落"🌱 有点蔫了"提示 | 完成 1 个番茄钟自动浇水复活 |
| **休眠** | 离线 >7 天 | 叶子卷曲 + 进度冻结（不消失、不倒退） | 完成 1 个番茄钟自动唤醒 |

**关键机制**：
- **无作物死亡**：离线永不删作物（区别于专注违规惩罚的枯萎机制——那是用户主动违规的代价）
- **进度冻结而非倒退**：7 天前的 90% 进度，7 天后还是 90%
- 状态存于 `garden.data.languish`：`{ level: 0|1|2, lastSeenAt }`

#### 5.3 与 v1"枯萎救援"的边界

| 机制 | 触发 | 表现 | 恢复 |
|------|------|------|------|
| 枯萎救援（v1，违规惩罚） | 专注模式违规 | 作物变枯萎态（wilted） | 完成 1 个番茄钟救活，再违规则永久清除 |
| 微黄/休眠（v2，离线召唤） | 离线/断签 | 叶子发黄/卷曲 | 完成 1 个番茄钟自动恢复 |

两者独立存储（`wilted` vs `languish`），互不干扰。离线不救枯萎（枯萎是违规代价，必须靠专注救），枯萎不产生微黄（避免状态混淆）。

### 维度 6：分享与社交轻触

#### 6.1 设计目标

菜园状态成为一张可分享的"专注成绩单"，但**分享是轻触**（用户主动、一键、无社交压力）。

#### 6.2 专注成绩单卡片

**触发**：专注结束后，菜园窗口顶部出现"分享今日"按钮（不自动弹窗）
**内容**（纯文本 + 图片双格式）：

```
🍅 今日专注成绩单
📅 8月8日
⏱ 专注 6 个番茄 · 180 分钟
🌾 收获 6 株作物（含 1 株闪光胡萝卜✨）
🔥 连击 ×4
🌱 段位 Lv2 繁茂
累计专注 42 小时
```

**交互**：
- 点击"分享"→ 生成卡片图片（Canvas 本地渲染 ≤2s）+ 复制文本
- 分享途径：保存图片 / 复制文本（由用户自行发到任意社交平台）

#### 6.3 社交轻触（与自习室联动）

- 自习室好友列表显示：**段位徽章 + 今日收获数**（轻量，不展示他人完整菜园，避免攀比焦虑）
- 不做"菜园 PK/排行榜"（违背"专注不焦虑"的价值观）

#### 6.4 数值

- 卡片生成：本地 Canvas，≤2s
- 分享触发：手动按钮，绝不自动弹窗
- 好友可见字段：段位徽章 + 今日收获数（仅 2 个字段）

## 2. 数据模型变更

### 2.1 GardenState 新增字段

```typescript
export interface ComboState {
  count: number;      // 当前连击数
  best: number;       // 历史最高连击
  active: boolean;    // 是否激活加成（count >= 3）
}

export interface LanguishState {
  level: 0 | 1 | 2;   // 0正常 / 1微黄 / 2休眠
  lastSeenAt: string | null; // 上次打开菜园时间
}

export interface TierState {
  current: number;    // 当前段位 0-3
  best: number;       // 历史最高段位
  graceStart: string | null; // 宽限期开始时间
}

export interface DailyCap {
  date: string;          // 记录日期 YYYY-MM-DD
  growthMinutes: number; // 当日已生长分钟
  coinsEarned: number;   // 当日已获金币
}

export interface EventState {
  petLastAt: string | null;      // 偷菜动物冷却
  mutated: string[];             // 已收集闪光作物（图鉴）
}

// Plot 新增
export interface Plot {
  id: number;
  crop: string | null;
  progress: number;
  plantedAt: string | null;
  locked?: boolean;
  wilted?: boolean;      // v1 枯萎（违规惩罚）
  mutated?: boolean;     // v2 闪光变异
}
```

### 2.2 数据落点（garden.json）

```json
{
  "combo": { "count": 2, "best": 5, "active": false },
  "languish": { "level": 0, "lastSeenAt": "2026-08-08T08:00:00Z" },
  "tier": { "current": 1, "best": 2, "graceStart": null },
  "dailyCap": { "date": "2026-08-08", "growthMinutes": 90, "coinsEarned": 40 },
  "events": { "petLastAt": null, "mutated": ["carrot"] },
  "plots": [
    { "id": 0, "crop": "carrot", "progress": 25, "plantedAt": "...", "locked": false, "wilted": false, "mutated": true }
  ]
}
```

## 5. 分阶段实施计划

### Phase A（已完成 v1）✅
- 专注连击 ×1.5（`garden_record_focus` + `apply_growth`）
- 枯萎救援（`apply_punishment` → wilted 态，专注救活）
- 后端纯函数 + 全部 Rust 单测

### Phase B（轻量交互 + 封顶）
- 主界面角标 + 状态点
- 快捷种植 / 一键全收
- 每日生长/金币封顶（`dailyCap`）
- 段位系统（`tier`）+ 微黄状态（`languish` level 1）
- 测试：封顶边界、段位计算、快捷种植推荐

### Phase C（彩蛋 + 休眠）
- 偷菜小动物（`events.petLastAt`）
- 变异闪光作物（`plot.mutated` + 图鉴）
- 流星雨（`garden_touch` 判定）
- 休眠状态（`languish` level 2）
- 测试：概率注入（mock RNG）、状态机

### Phase D（分享 + 装扮）
