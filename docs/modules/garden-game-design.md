## 0. 设计理念

### 0.1 一句话定位

> **菜园是专注的影子，不是主菜。**

用户打开 App 的核心目的是"专注"，菜园只是把"专注了多久"翻译成看得见的反馈。一切设计必须服从这条铁律。

### 0.2 四条铁律

1. **轻**：所有种菜操作 ≤5 秒完成、≤2 步，绝不打断专注流程
2. **平**：成长体系极端扁平，专注 1 小时和 8 小时的用户菜园差异 ≤3 倍，杜绝"种菜焦虑"
3. **暖**：离线/断签只温和召回，绝不惩罚（无作物死亡、无进度清空——专注违规惩罚是另一套独立机制）
4. **峰**：情绪峰值靠低频彩蛋（偷菜小动物、变异闪光、流星雨），不靠数值膨胀

## 1. 六维度设计详解

### 维度 1：用户接受门槛（极度轻量）

#### 1.1 问题

当前菜园是独立窗口（400×520），需要用户主动打开；种植需要"点空地 → 轮盘选种"两步。对"只想专注"的用户，任何一个多余步骤都是流失点。

#### 1.2 交互设计

| 场景 | 当前 | 重构后 | 操作耗时 |
|------|------|--------|----------|
| 查看菜园状态 | 打开独立窗口 | 主界面右下角 32px 角标 + 状态点（收获就绪亮黄点） | 0s（无需操作） |
| 进入菜园 | 打开窗口 | 点角标 → 窗口秒开（预加载） | ≤1s |
| 种植 | 点空地 → 轮盘选种 | **快捷种植**：点空地默认种"当前最优种子"（按库存/性价比），长按才出轮盘 | ≤3s |
| 收获 | 逐块点击成熟作物 | **一键全收**：成熟作物全部入库 + 角标熄灭 | ≤2s |
| 出售 | 进商店逐项卖 | 一键出售（已有 sell_all）+ 商店批量 | ≤2s |
| 反馈 | — | 所有种菜反馈用**角标/轻提示**，不用模态弹窗 | — |

**交互细则**：
- 主界面角标：`🍅` 图标 + 右上角状态点（绿色=生长中，黄色=有成熟待收，红色=有枯萎待救，🎪=商人在线）
- 菜园窗口顶部常驻一行"状态条"：`🌱 3块地生长中 · 2 株待收 · 🔥连击×2`
- 快捷种植的"最优种子"算法：优先选 `库存中性价比最高且能在预计剩余专注时间内成熟` 的种子
- 所有按钮触控目标 ≥ 44px；菜园窗口保持 400×520 固定尺寸
- 专注过程中菜园**完全后台静默生长**，不弹任何窗口

#### 1.3 数值

- 单次操作耗时目标：种植 ≤3s、收获 ≤2s、其他 ≤5s
- 主界面菜园入口视觉面积：1 个 32px 图标（不占导航空间）
- 状态点颜色映射：绿/黄/红/🎪 四态

### 维度 2：难度/激励梯度（段位可视化）

#### 2.1 问题

现有"成就系统"是横向清单（25 个），没有纵向的"段位成长"感知。用户不知道自己"坚持专注"会带来什么形态变化。

#### 2.2 段位系统设计

**段位 = 连续专注天数**（复用现有 `signIn.continuousDays`，语义一致）

| 段位 | 名称 | 连续天数 | 菜园形态变化 |
|------|------|----------|--------------|
| Lv0 | 萌芽 | 0-6 | 光秃秃的土地 |
| Lv1 | 初绿 | 7 | 出现栅栏、小草、微风动画 |
| Lv2 | 繁茂 | 14 | 蝴蝶飞舞、花朵装饰、土地变沃土色 |
| Lv3 | 丰收 | 30 | 金色麦浪、彩虹、星星粒子 |

**交互示意**：
- 菜园背景随段位渐变（CSS 渐变 + 装饰元素），升段时有 1 秒粒子庆祝动画
- 主界面角标显示段位小徽章（`Lv1` 字样）
- 段位解锁额外**装扮碎片**（见维度 3 数值出口）

#### 2.3 断签处理（轻惋惜、不劝退）

| 断签时长 | 视觉 | 影响 | 恢复方式 |
|----------|------|------|----------|
| 0-3 天（宽限期） | 叶子微微发黄 | 段位保留 | 完成 1 个番茄钟自动恢复翠绿 |
| 超过 3 天 | 叶子明显发黄 + 角落提示 | **段位降 1 级**（Lv2→Lv1，绝不直接清零） | 完成 1 个番茄钟恢复生机，段位按当前连续天数重新计算 |

**关键设计**：
- 断签 ≠ 惩罚：不扣金币、不消失作物、不重置成就
- 降级是"软着陆"：每次只降 1 级，最低到 Lv0，永远保留"历史最高段位"记录供展示
- 断签提示文案温暖化："🌱 你的菜园有点蔫了，完成一个番茄钟就能恢复生机"

#### 2.4 数值

- 段位阈值：7 / 14 / 30 天（与现有签到里程碑 7/14/30 对齐）
- 宽限期：3 天（断签 1-2 天内心态无压力）
- 降级：超过宽限期降 1 级/次，最低 Lv0
- 历史最高段位：永久记录（`tierBest`），用于成就/分享

### 维度 3：数值克制 + 经济系统重设计（作物即资产）

#### 3.1 问题诊断

现有经济循环是 **买种子(金币) → 种 → 收 → 卖(金币) → 再买种子**。金币是唯一中间物，作物只是"金币的临时形态"。三个病灶：

1. **单调**：没有决策、没有积累感、没有惊喜
2. **性价比曲线单调递增**：解锁贵的就永远不种便宜的
3. **"卖钱"是唯一出口**：作物变钱的方式太粗暴，没有时机和选择

#### 3.2 核心转变：作物即资产，钱只是多种出口之一

借鉴 HayDay 式设计，作物本身是**可繁殖、可加工、可交易**的资产，而不是货币的临时载体。

```
每日配额（生长 120 分钟封顶）
  → 种下种子
  → 收获作物（可留种回种 → 自持繁殖循环）
  → 出口决策（5 选 1 或组合）：
      A. 留种繁殖 —— 作物变作物，扩产（HayDay）
      B. 合成台加工 —— 原料 → 高级品，价值 ×1.2-1.5
      C. 等市场涨价 —— 炒股，每日价格波动 ±30%
      D. 等随机商人 —— 限时高价 / 物物交换（+30~60% 或换稀有种子）
      E. 直接卖店 —— 保底价 60%，最差路径
  → 金币：初始种子 / 装饰 / 土地
  → 星星币（加工品/商人稀有交易产出）：稀有装扮 / 稀有种子
```

#### 3.3 作物繁殖（HayDay 核心：种下去收获更多）

| 作物 | 收获产出 | 留种规则 | 设计意图 |
|------|----------|----------|----------|
| 🥕 胡萝卜 | 1 种 → 收 3 | 1 作物可留种回种 | 低阶作物扩产快，新手正反馈 |
| 🍅 番茄 | 1 种 → 收 3 | 1 作物可留种回种 | 同上 |
| 🌻 向日葵 | 1 种 → 收 2 | 1 作物可留种回种 | 中阶，稀缺感 |
| 🌹 玫瑰 | 1 种 → 收 2 | 1 作物可留种回种 | 中阶 |
| 🌳 金桂树 | 1 种 → 收 1-2 | 1 作物可留种回种 | 高阶，产量低价值高 |

**关键机制**：收获的作物可以直接"留种"（1 作物 → 1 种子）种回地里。日常循环**完全自持**，不需要金币买种子——金币只在"起步"和"扩张（装饰/土地）"时需要。这就是"作物变作物"的字面实现。

#### 3.4 合成台（加工增值，延迟满足）

| 配方 | 产物 | 价值倍数 |
|------|------|----------|
| 2 胡萝卜 + 1 番茄 | 炖菜 | 原料总和 ×1.2 |
| 3 番茄 + 1 向日葵 | 番茄意面 | 原料总和 ×1.3 |
| 2 玫瑰 + 1 金桂 | 金桂礼盒 | 原料总和 ×1.5 |
| 3 金桂树 | 金桂王冠 | 原料总和 ×1.5 + 星星币 |

- 加工品**只能卖给商人/市场**（不能直接卖店），强制走交易系统
- 加工品是**星星币**的主要来源（稀有装扮的货币）
- 配方表固定可查（"合成台"页签展示配方 + 进度）

#### 3.5 随机商人（重定位：不做现金收购，聚焦"以物易物"）

**取舍结论**：既然市场/商店已提供价格浮动（炒股乐趣），商人再做"随机现金收购"就与市场功能重叠、失去意义。**商人砍掉现金收购，只做市场做不到的事**：

- **物物交换**：如 5 胡萝卜 ↔ 1 向日葵种子、8 番茄 ↔ 1 玫瑰种子（市场不提供以物易物）
- **加工品收购**：合成台产物**只能卖给商人**（换星星币）——这是加工品的唯一出口，强制进入交易系统
- **稀有商品**：限量出售稀有种子/装扮（星星币专属）

**刷新**：每天 2-3 次随机时刻（30-60 分钟停留），菜园窗口"🎪 商人来了"角标 + 倒计时
**限购**：每单限购 3-5 个，防刷

**分工定位（关键设计，避免功能重叠）**：

| 出口 | 卖什么 | 给什么 | 何时 |
|------|--------|--------|------|
| 商店 | 普通作物 | 金币（保底 60%） | 随时，安全网 |
| 市场 | 普通作物 | 金币（浮动 ±30%） | 等时机，炒股 |
| 商人 | 加工品 / 以物易物 | 星星币 / 稀有种子 | 限时，机会 |
| 合成台 | 原料 → 加工品 | 加工品（×1.2-1.5 + 星星币） | 主动 |

#### 3.6 本地市场（炒股系统）

- **行情**：每种作物每日价格 = 基础价 × (1 + 波动)，波动 ±30%，**由确定性种子生成**（seed + 日期 → 可测试、可复现、可预览）
- **操作**：随时可按当前价卖出；可囤仓等明天涨价
- **展示**：商店页签内嵌"今日行情"区块，显示今日价格 + 涨跌箭头 + 最近 7 日走势迷你图（不再单独开"市场"页签，减少导航负担）
- **克制**：波动温和（±30% 封顶），不极端不赌徒——低风险、有决策、有期待
- **与商人的分工**：市场是"现金时机的自然波动"，商人是"以物易物的机会窗口"，功能不重叠

#### 3.7 数值平衡（全面斟酌）

| 参数 | v2 草案 | v3 定稿 | 理由 |
|------|---------|---------|------|
| 连击生长加成 | ×1.5 | **×1.2**（封顶） | 1.5 太强，会诱导"为了种菜过度专注"，违背产品初衷 |
| 连击阈值 | 3 | **2** | 降低门槛，更快感受到正反馈 |
| 连击品质奖励 | 无 | **收获闪光概率 = 3% + 连击×1%（封顶 10%）** | 连击奖励"惊喜"而非"速度"，符合"峰"原则 |
| 每日生长配额 | 120 分钟 | 120 分钟（保留） | 控制总产出，防止过度专注 |
| 金币每日上限 | 100（硬封顶） | **取消硬封顶，改为交易出口自然调节** | 出口多样后无需硬闸门，让玩家决策 |
| 商店回收价 | 100% | **60%（保底）** | 让"直接卖店"成为最差路径，激励走市场/商人/加工 |
| 市场波动 | 无 | ±30% | 温和炒股 |
| 商人功能 | 无 | **物物交换 + 加工品出口 + 稀有商品**（砍现金收购） | 与市场功能不重叠 |
| 繁殖 | 无 | 1→2/3（见 3.3） | HayDay 式扩产 |
| 合成 | 无 | ×1.2-1.5 | 延迟满足 |
| 巨大化 | 无 | 3×3 同作物成熟 → 9 株价值 ×1.5 + 星星币 | 布局规划的意义，wow moment |

#### 3.8 专注 1 小时 vs 8 小时对比（复核）

| 指标 | 专注 1 小时 | 专注 8 小时 | 差异 |
|------|------------|------------|------|
| 有效生长 | 120 分钟（上限） | 120 分钟（封顶） | 1:1 |
| 收获次数 | 4-5 株 | 4-5 株 | 1:1 |
| 金币/资产 | 40-60（走市场） | 40-60（封顶） | 1:1~1.5 |
| 交易决策乐趣 | 有 | 有 | 平等 |

**结论**：扁平原则不变，但"资产价值"让用户有选择权（何时卖、卖谁、加工还是繁殖），游戏性来自**决策**而非**时长**。

#### 3.9 交互示意

- 菜园窗口新增底部导航：`土地 | 背包 | 合成 | 商店`（商店页签内嵌"今日行情"；商人出现时加"🎪"角标）
- 商店页签：分两个区块——"今日行情"（浮动价 + 涨跌箭头 + 7 日走势）和"商店回收"（保底 60%）
- 商人弹窗：限时倒计时 + 收购单列表（物物交换/加工品收购，可逐单接受/拒绝）
- 合成台：配方卡 + "合成"按钮 + 产出预览
- 所有出口都保留"直接卖店"保底，用户永远有退路

#### 3.10 巨大化（星露谷式：3×3 同作物，概率触发）

**修正（v3.2）**：原设计"3×3 必然巨大化"过于廉价。参考星露谷，巨大化是**收获时的概率事件** + 布局约束，而不是布局白送。

- **前提**：3×3 相邻格子种**同一种作物**且全部成熟（布局入场券）
- **触发**：收获中心格时，**15% 概率**出现巨型作物（🌻 变大 + 金光 + 2 秒动画）——不是必然
- **收获**：巨型作物 = 该作物 9 株价值 ×1.5 + 星星币 + 点亮图鉴"巨型版"条目
- **不可再生**：巨型作物一次性收获，9 格全部清空（与星露谷一致，制造"错过就没"的稀缺感）
- **设计意图**：布局规划（决策感）+ 概率（惊喜感）双门槛，wow moment 不廉价
- **概率参考**：星露谷巨型作物约 1%/次，玩很久遇不到（用户反馈存在感太弱）；我们取 **15%**，布局成本（3×3 对齐）本身已是门槛，15% 保证"能遇到但靠运气"
- **边界**：地块不足 3×3 连续区域时不触发（被锁定土地/枯萎隔断）；一次收获只结算一种特殊状态（见 3.12）

#### 3.11 生动性方案（世界会回应你）

**取舍**：生动性不靠重写系统，靠"表现层"低成本叠加。按性价比分优先级：

| 层级 | 方案 | 成本 | 感知 |
|------|------|------|------|
| P0 | **作物生长动画**：种子→幼苗→成株→成熟 4 阶段（CSS） | 低 | 高 |
| P0 | **成熟"点头"动画**：成熟作物轻微摇晃召唤收获（CSS） | 低 | 高 |
| P1 | **季节背景**：随真实月份变化（春绿/夏花/秋金/冬雪，CSS 渐变 + 装饰） | 低 | 中 |
| P1 | **收获/种植轻音效** | 低 | 中 |
| P2 | **随机小动物活动**：蝴蝶/萤火虫飘过（粒子动画） | 中 | 中 |
| P2 | **天气叠加**：随机小雨/阳光/彩虹（纯前端） | 中 | 中 |

**明确不做**：完整昼夜循环、复杂物理、多人世界（工作量爆炸，违背"轻"铁律）。

#### 3.12 机制叠加控制（组合爆炸治理）

**问题**：v3 叠加了 13+ 机制（繁殖/合成/商人/市场/巨大化/闪光/彩蛋/段位…），不加控制会组合爆炸：一次收获可能同时闪光+巨大化+繁殖回本，经济失衡；多个系统互相耦合，用户困惑。

**三条控制规则（v3.2 新增）**：

1. **一次收获只结算一种特殊状态**（优先级：巨大化 > 闪光 > 正常）——同一株作物不可能既是巨型又是闪光，防止数值爆炸
2. **经济双轨隔离**：金币（日常循环）与星星币（装扮/稀有）**不可互换**，星星币只能通过加工品/巨大化/商人获得——防止"刷金币→刷星星"单一路径
3. **产出物类型锁定**：加工品只能卖商人、巨型作物一次性、闪光作物价值 ×3 但仍是普通作物——每种产出有且只有一个出口，避免"最优路径"收敛成唯一解

#### 3.13 渐进引入节奏（防认知过载）

**问题**：新手第一天面对"种植/留种/合成/市场/商人/巨大化/彩蛋/段位/装扮"一屏系统，必然晕头转向。

**方案**：机制按**使用天数 + 行为里程碑**逐步解锁，未解锁的系统在导航栏显示为"🔒 连续专注 X 天解锁"：

| 解锁时机 | 解锁机制 | 引导文案 |
|----------|----------|----------|
| 第 1 天（默认） | 种植 / 收获 / 商店（保底价） | — |
| 首次收获后 | 留种繁殖 | "收获的作物可以留种再种！" |
| 第 3 天 或 首次连击 | 市场（今日行情） | "作物价格每天波动，看准时机卖" |
| 第 7 天（Lv1） | 合成台 + 星星币 | "把作物加工成高级品，换星星币" |
| 第 14 天（Lv2） | 随机商人 | "🎪 商人来了，可用作物以物易物" |
| 第 30 天（Lv3） | 巨大化 + 彩蛋 | "种满 3×3 同种作物，可能长出巨型作物！" |

**设计意图**：用户每天只学 0-1 个新机制，每解锁一个都有明确的期待感（"明天能玩到啥"），而不是第一天面对全部系统。高级机制（商人/巨大化/彩蛋）天然奖励"坚持 30 天"的老用户，符合"奖励坚持"的价值观。

### 维度 4：惊喜与随机性（低频彩蛋）

#### 4.1 设计原则

彩蛋**只增不减**（只给奖励不扣东西）、**低频**（防止麻木）、**低成本实现**（纯前端 + 少量后端状态）。

#### 4.2 三个彩蛋

##### 彩蛋 A：偷菜小动物 🐿️

- **触发**：专注结束后 5% 概率
- **表现**：菜园角落出现一只随机小动物（松鼠/兔子/刺猬，跑动动画）
- **交互**：点击小动物 → 抖动 + 掉落奖励（随机种子 1-2 颗 或 5-10 金币）
- **冷却**：24 小时（防止刷）

##### 彩蛋 B：变异闪光作物 ✨（与连击品质联动）

- **触发**：收获时概率 = **3% + 连击×1%（封顶 10%）**——连击越高，出闪光越爽
- **表现**：收获动画变闪光特效，作物图标带 ✨ 标记
- **奖励**：该株作物价值 ×3
- **附加**：点亮图鉴"闪光版"条目（收集钩子，收集全部 5 种闪光作物有专属成就）
- **设计意图**：把连击奖励从"生长加速"转为"品质惊喜"，见维度 3 数值斟酌

##### 彩蛋 C：流星雨 🌠

- **触发**：连续专注 3 天后，次日首次打开菜园 10% 概率
- **表现**：菜园背景 5 秒流星动画
- **奖励**：掉落 1 颗稀有种子（向日葵/玫瑰）
- **冷却**：无（本身低概率）

#### 4.3 数值汇总

| 彩蛋 | 概率 | 冷却 | 奖励 |
|------|------|------|------|
| 偷菜小动物 | 5%/次专注结束 | 24h | 种子 1-2 颗 或 5-10 金币 |
| 变异闪光 | 3%/次收获 | 无 | 价值 ×3 + 图鉴条目 |
| 流星雨 | 连续 3 天 + 10% | 无 | 稀有种子 1 颗 |

**情绪峰值验证**：三天彩蛋分布在"专注结束/收获/次日打开"三个不同时刻，制造低频但稳定的期待感。

### 维度 5：离线/断签处理（温和召唤）

#### 5.1 设计原则

> 用户不是欠菜园的，菜园是等用户的。任何离线状态都**不惩罚、可逆转、带召唤感**。

#### 5.2 三级状态机

| 状态 | 触发条件 | 视觉 | 恢复方式 |
|------|----------|------|----------|
| 正常 | 活跃使用 | 翠绿 | — |
| **微黄** | 断签/离线 >24h | 叶子颜色变淡、角落"🌱 有点蔫了"提示 | 完成 1 个番茄钟自动浇水复活 |
| **休眠** | 离线 >7 天 | 叶子卷曲 + 进度冻结（不消失、不倒退） | 完成 1 个番茄钟自动唤醒 |

**关键机制**：
- **无作物死亡**：离线永不删作物（区别于专注违规惩罚的枯萎机制——那是用户主动违规的代价）
- **进度冻结而非倒退**：7 天前的 90% 进度，7 天后还是 90%
- 状态存于 `garden.data.languish`：`{ level: 0|1|2, lastSeenAt }`

#### 5.3 与 v1"枯萎救援"的边界

| 机制 | 触发 | 表现 | 恢复 |
|------|------|------|------|
| 枯萎救援（v1，违规惩罚） | 专注模式违规 | 作物变枯萎态（wilted） | 完成 1 个番茄钟救活，再违规则永久清除 |
| 微黄/休眠（v2，离线召唤） | 离线/断签 | 叶子发黄/卷曲 | 完成 1 个番茄钟自动恢复 |

两者独立存储（`wilted` vs `languish`），互不干扰。离线不救枯萎（枯萎是违规代价，必须靠专注救），枯萎不产生微黄（避免状态混淆）。

### 维度 6：分享与社交轻触

#### 6.1 设计目标

菜园状态成为一张可分享的"专注成绩单"，但**分享是轻触**（用户主动、一键、无社交压力）。

#### 6.2 专注成绩单卡片

**触发**：专注结束后，菜园窗口顶部出现"分享今日"按钮（不自动弹窗）
**内容**（纯文本 + 图片双格式）：

```
🍅 今日专注成绩单
📅 8月8日
⏱ 专注 6 个番茄 · 180 分钟
🌾 收获 6 株作物（含 1 株闪光胡萝卜✨）
🔥 连击 ×4
🌱 段位 Lv2 繁茂
累计专注 42 小时
```

**交互**：
- 点击"分享"→ 生成卡片图片（Canvas 本地渲染 ≤2s）+ 复制文本
- 分享途径：保存图片 / 复制文本（由用户自行发到任意社交平台）

#### 6.3 社交轻触（与自习室联动）

- 自习室好友列表显示：**段位徽章 + 今日收获数**（轻量，不展示他人完整菜园，避免攀比焦虑）
- 不做"菜园 PK/排行榜"（违背"专注不焦虑"的价值观）

#### 6.4 数值

- 卡片生成：本地 Canvas，≤2s
- 分享触发：手动按钮，绝不自动弹窗
- 好友可见字段：段位徽章 + 今日收获数（仅 2 个字段）

### 2.1 GardenState 新增字段

```typescript
export interface ComboState {
  count: number;      // 当前连击数
  best: number;       // 历史最高连击
  active: boolean;    // 是否激活加成（count >= 2）
}

export interface LanguishState {
  level: 0 | 1 | 2;   // 0正常 / 1微黄 / 2休眠
  lastSeenAt: string | null; // 上次打开菜园时间
}

export interface TierState {
  current: number;    // 当前段位 0-3
  best: number;       // 历史最高段位
  graceStart: string | null; // 宽限期开始时间
}

export interface DailyCap {
  date: string;          // 记录日期 YYYY-MM-DD
  growthMinutes: number; // 当日已生长分钟（上限 120）
}

export interface EventState {
  petLastAt: string | null;      // 偷菜动物冷却
  mutated: string[];             // 已收集闪光作物（图鉴）
  merchant: {                    // 随机商人
    active: boolean;
    expiresAt: string | null;    // 商人停留截止
    offers: MerchantOffer[];     // 收购单 / 物物交换单
  };
}

export interface UnlockState {
  marketAt: string | null;       // 市场解锁时间（第 3 天或首次连击）
  craftAt: string | null;        // 合成台解锁时间（第 7 天）
  merchantAt: string | null;     // 商人解锁时间（第 14 天）
  giantAt: string | null;        // 巨大化解锁时间（第 30 天）
  petAt: string | null;          // 彩蛋解锁时间（第 30 天）
}

export interface MerchantOffer {
  type: "coins" | "swap";      // 金币收购 / 物物交换
  item: string;                // 收购的作物/加工品
  count: number;               // 限购数量
  price?: number;              // type=coins 时：单件收购价（基础价 70%-160%）
  swapFor?: { item: string; count: number }; // type=swap 时：换什么
}

export interface MarketPrice {
  item: string;      // 作物或加工品
  today: number;     // 今日价（基础价 ±30%）
  history: number[]; // 最近 7 日走势
}

// Plot 新增
export interface Plot {
  id: number;
  crop: string | null;
  progress: number;
  plantedAt: string | null;
  locked?: boolean;
  wilted?: boolean;      // v1 枯萎（违规惩罚）
  mutated?: boolean;     // v2 闪光变异
}

// 合成配方
export interface Recipe {
  id: string;
  output: string;               // 产物（加工品 key）
  ingredients: Record<string, number>; // 原料表 { 作物key: 数量 }
  valueMultiplier: number;      // 价值倍数（×1.2-1.5）
  starReward: number;           // 星星币奖励
}
```
