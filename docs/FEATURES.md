## 🍅 计时器系统

### 三种计时模式

| 模式 | 说明 | 使用场景 |
|------|------|---------|
| **单次** | 选择一个时间，点击开始 | 一次专注一个任务 |
| **正向** | 从 0 开始向上计数 | 不确定需要多久的任务 |
| **计划** | 多任务队列自动依次执行 | 一整天的学习/工作计划 |

**计划模式特有功能**：拖拽排序、自动推进下一项、AI 助手一键生成

**计划模式执行与配色**：
- 点击「开始」从计划第一项启动，完成一项自动进入下一项（1 秒后自动开始），全部完成自动停止
- 容器整体颜色跟随**当前即将开始/正在进行的计时项**：工作项 = 工作色（红），休息项 = 休息色（绿）；进入计划模式未开始时按第一项着色
- 运行中「重置」= 停止整个计划；专注模式开启时运行中重置/中断 = 惩罚（作物枯萎）并停止计划

### 计时技术
采用**时间戳计算**而非 setInterval 累加，即使窗口最小化或后台运行，计时依然准确。

### 🥚 隐藏彩蛋

在**设置面板**中连续点击**版本号 5 次**（每次间隔 < 1.5s）即可触发：
1. 版本号位置彩色粒子飞散
2. 解锁隐藏成就「发现彩蛋」（🥚，奖励 🌳金桂树种子×1 + 50 金币，幂等不重复发放）
3. 全屏「太空旅行」动画（深空背景 + 星星 + 行星 + 🍅 番茄火箭升空 + 感谢信息，8 秒后可点击 / ESC 返回）

入口位于设置面板底部「版本」行，彩蛋状态持久化在菜园子数据中（`achievements.easteregg`）。

### 惩罚机制

**专注模式 = 奖惩机制开关**：开启后菜园子的菜才会成长（计时器运行期间每分钟 +1 分钟），前台检测才会启动；断掉专注模式（警告 / 重置 / 手动关闭）会导致**所有未成熟的作物枯萎**，并弹出损失明细弹窗（每株作物的图标 / 名称 / 已生长分钟 + 总损失分钟）。

| 触发行为 | 后果 |
|---------|------|
| 前台检测累积 3 次警告 | 🥀 作物枯萎 + 计时重置 + 专注模式关闭 + 损失弹窗 |
| 专注模式运行中手动点「重置」（中断专注） | 🥀 作物枯萎 + 计时重置 + 专注模式关闭 + 损失弹窗 |
| 专注模式开启后手动关闭开关（未完成番茄钟） | 🥀 作物枯萎 + 专注模式关闭 + 损失弹窗 |
| 专注模式开启后自然完成番茄钟再关闭开关 | 仅关闭开关，**不惩罚**（专注承诺已兑现） |

**保护机制**：专注模式运行中禁用暂停按钮（点击无效，含空格键），运行中专注模式开关不可拨动；惩罚后的损失明细通过独立弹窗展示（无损失时显示"幸好没有正在生长的作物"）。

## 🔍 专注模式 & 前台检测

### 开启方式
点击计时器下方的「专注模式」开关（受控组件，惩罚后自动归位）。开启后：
- 番茄钟运行期间菜园子每分钟成长（`garden_grow`，仅专注模式开启时）
- 计时器处于工作模式时自动启动前台检测

### 检测逻辑

```
前台窗口变化 → 匹配白名单（放行）
           → 匹配黑名单（警告）
           → 查询 AI 历史记录
           → 调用 DeepSeek AI 判断
```

前台窗口标题通过 Windows `GetForegroundWindow` + `GetWindowTextW` 抓取（`modules/foreground_inspection.rs`），已在本地实测可正确获取前台应用名称。

### 黑白名单

| 类型 | 默认内容 |
|------|---------|
| 白名单 | 文件资源管理器、VS Code、PowerPoint、番茄钟自身等 |
| 黑名单 | bilibili、抖音、快手、斗鱼、虎牙 |

### 警告与惩罚

| 警告次数 | 效果 |
|:--------:|------|
| 1-2 次 | 弹窗提醒 |
| 3 次 | 🥀 作物枯萎 + 计时重置 + 专注模式关闭 + 损失弹窗 |

用户可选择「知道了」（接受警告）或「不是娱乐」（标记为白名单）。
专注模式关闭或计时器停止后，迟到的检测广播会被忽略（不再误弹窗）。

## 🤖 AI 规划助手

用自然语言描述需求，AI 自动生成番茄钟计划。

**示例输入**：`明天要考试，需要复习数学 3 小时`

**AI 输出**：
```
📋 为您规划了 3 小时的数学复习计划
1. 💼 工作 45分钟 - 复习数学第一部分
2. ☕ 休息 10分钟
3. 💼 工作 45分钟 - 复习数学第二部分
...
⏱️ 总计: 3小时5分钟
```

> 需要 Admin 用户登录（使用 DeepSeek API）。

### 两种模式

| 模式 | 说明 |
