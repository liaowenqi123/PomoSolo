# 2026-04-05 工作日志

## 修复：惩罚弹窗显示"幸好没有正在生长的作物"的 bug

**文件：** `src/scripts/modules/garden.js` - `handleResetPunishment()`

**根本原因：**
- `garden.js` 被 `index.html` 加载，`window.Garden` 存在于主窗口上下文。
- `handleResetPunishment` 在 IPC 成功返回 `{ hasLoss: true, ... }` 后调用 `loadAndRender()`。
- `loadAndRender` 调用 `render()` → `renderCoins()` 等，这些函数直接访问 `elements.coinCount` 等 DOM 节点，但这些节点只存在于 `garden.html`，在 `index.html` 上下文中全为 `null`，导致 `TypeError`。
- 该异常被原来的大 try-catch 捕获，返回了 `{ hasLoss: false, losses: [], totalMinutes: 0 }`，弹窗因此显示"幸好没有正在生长的作物"。

**最终修复方案（v2，正确解法）：**
1. `init()` 开头增加页面检测：`if (!document.getElementById('gardenGrid')) return`，非菜园子页面直接退出，不初始化任何 DOM 或事件绑定。
2. 新增模块级变量 `isGardenPage = false`，`garden.html` 上执行时置为 `true`。
3. `handleResetPunishment` 去掉所有 try-catch，用明确的 `isGardenPage` 判断决定是否刷新 UI：
   ```js
   const result = await window.electronAPI.gardenPunishment()
   if (result.hasLoss && isGardenPage) {
     await loadAndRender()
     updateTip('...')
   }
   return result
   ```
   IPC 调用本身如报错会正常向上抛，不再用 catch 掩盖。
